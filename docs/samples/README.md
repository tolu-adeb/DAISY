# Sample pitches

Made by `abg` from the **synthetic** test panel (tickers S00–S59 are random walks) with invented
company facts, to show the AIBG pitch format and its arithmetic. None of it is a recommendation.

| File | What |
|---|---|
| `memo_buy_pullback.md` | BUY from the trend-pullback book, with valuation, charts and a "views disagree" banner |
| `memo_buy_meanrev.md` | BUY from the mean-reversion book (T1 is the rule's 5-day-average exit) |
| `memo_sell.md` | SELL: the rule's exit, what the trade did, and what the team should learn |
| `deck_buy_pullback.pptx` | The first pitch as the AIBG 5-slide deck (`abg pitch deck SYMBOL`) |
| `*.png` | The charts the memos embed |

| `watchlist_post.md` | The 08:45 morning watchlist digest (docs/22.4) |
| `live_alert.md` | A live alert with several changes bundled into one post (docs/22.5) |
| `weekly_recap.md` | The Friday recap (docs/22.7) |
| `screens/*.jpg` | The dashboard: each destination at 1440px (dark) and 375px (light), a deep-dive view, and `before-classic-1440.jpg` for the page it replaced (docs/22.6) |

The watchlist, alert and screenshot samples use the test suite's panel (tickers T00–T23). They are
sample data, not real companies and not real signals.

See docs/21-stock-desk.md, section 21.6, and docs/22-pitching-desk.md.
